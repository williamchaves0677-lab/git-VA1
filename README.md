# Portfólio Simples - William de Amorim

## Descrição
Este é um projeto de uma página pessoal estática, desenvolvido como parte da Verificação de Aprendizagem (VA1) da disciplina de Gestão do Conhecimento.

## Objetivo
O objetivo principal é criar um site para apresentar minhas informações pessoais, interesses e habilidades, além de praticar o versionamento de desenvolvimento com Git e o compartilhamento do projeto no GitHub.

## Tecnologias Utilizadas
* HTML
* CSS
* Git e GitHub
